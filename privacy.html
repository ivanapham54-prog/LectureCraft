LectureCraft Privacy Policy

Last updated: May 5, 2026

Overview

LectureCraft is a custom GPT action that helps users work with Google Calendar and Google Drive after they grant permission through Google OAuth. LectureCraft only uses access that the user explicitly authorizes.

Information LectureCraft accesses

When authorized, LectureCraft may access Google Calendar event data and Google Drive file metadata needed to create calendar events, find files, attach Drive documents to calendar events, and share selected files with attendees.

How information is used

LectureCraft uses authorized Google data only to complete user-requested actions, such as listing calendar events, creating or updating an event, finding a Drive file, attaching a document, or sharing a selected file.

Data sharing

LectureCraft does not sell user data. LectureCraft does not share Google user data except as needed to perform actions requested by the user, such as sharing a Drive file with an attendee email address the user provides or approves.

Data storage

LectureCraft does not intentionally store Google Calendar or Drive content outside the services needed to process the user's request in ChatGPT and Google APIs. Users can revoke Google OAuth access at any time from their Google Account permissions.

Security

LectureCraft uses Google OAuth for authorization. Users should only approve access when they understand the requested permissions and intend to use the connected Google workflow.
